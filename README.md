# Mahady AI — LinkedIn Personal Brand Agent

Next.js foundation for an AI workspace that will understand Mahady's professional profile, improve LinkedIn positioning, generate experience-led posts, maintain a calendar, publish through an authorized LinkedIn workflow, and learn from performance.

## Current phase

v0.1 is the dashboard/product foundation. No LinkedIn credentials are stored in source control.

## Planned integrations

- LinkedIn OAuth / approved publishing API
- Supabase for profile knowledge, posts, schedules and analytics
- AI model provider for content generation
- Vercel Cron for daily automation
